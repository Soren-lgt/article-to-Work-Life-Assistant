# 工作生活助手 App

本机运行的个人「工作 + 生活」管理工具，纯前端单页应用，数据存于浏览器 IndexedDB，
通过导出备份 JSON 兜底，不依赖任何运行期第三方库与后端服务。

## 一、功能模块（7 个一级模块）

| 模块 | 主要能力 |
|---|---|
| 首页总览 | 问候；今日待办（可勾选回写）；快速备忘（回车保存）；记账 / 同组 / 题库摘要联动 |
| 今日计划 | 按天管理待办、优先级、备注；勾选完成；前一天 / 后一天 / 今天切换；月度概览 |
| 每日记账 | 分类卡片（预置可改名删除新建）；记一笔（金额可空 + 备注）；日期选择器回看；当天记录列表可删；月度汇总 |
| 开发工作 | 开发任务（按项目分组、状态流转、编辑）；Bug 记录（四状态、编辑）；代码片段（展开 / 复制 / 删除） |
| 题库 | 选择 / 问答 / 代码三类；题库与题目管理；顺序练习即时反馈；考试模式倒计时自动交卷；成绩历史、错题回看与参考答案 |
| 同组计划 | 小组角色（组长 / 副组长 / 成员）；加入码申请与审核；项目看板（待办 / 待审核 / 已完成）；任务确认 / 驳回；文件附件；操作日志；通知已读 |
| 数据与设置 | 账号管理（建 / 改名 / 改密 / 删除级联）；本地密码哈希；默认首页 / 主题（浅色 / 深色）；记账初始卡片；全量导出 / 导入校验 / 备份清理 |

## 二、技术栈

- 原生 HTML + CSS + 原生 JavaScript（ES Module，无框架、无构建、无运行期依赖）
- 存储：IndexedDB（`worklife_v1`）；主题与默认首页存 localStorage
- 测试：Node.js 内置 `node:test` + 内存仓储适配器（业务逻辑与 UI 解耦，可在 Node 直接跑）
- 本地静态服务：Python 标准库 `http.server`（零第三方依赖）

## 四、运行方式

### 方式一：双击脚本（推荐）
- Windows：双击 `启动.cmd`；停止双击 `停止.cmd`
- macOS / Linux：终端执行 `./启动.command`

### 方式二：命令行
```
python server.py          # 启动并自动打开浏览器（8000 起自动选空闲端口）
python server.py status   # 查看运行状态
python server.py stop      # 停止
```
> 说明：直接双击 `app/index.html` 也能打开，但部分浏览器对 `file://` 下的 IndexedDB 支持受限，
> 统一通过本地 `http://127.0.0.1` 访问最稳妥。

## 五、运行测试

无需安装依赖（仅使用 Node 内置测试运行器）：

```
cd app
npm test                 # 运行全部测试
npm run test:m0          # 单独运行某一里程碑（test:m1 ~ test:m8）
```

测试覆盖：数据 Schema、工具函数、账号、今日计划 / 备忘、记账、开发工作、题库判分、
同组权限与状态机、备份往返，以及模块契约、HTML 结构、主题样式等。

## 六、数据与安全边界（第一版）

- 数据仅保存在本机浏览器；换浏览器 / 清缓存前请先在「数据与设置」导出备份 JSON。
- 本地密码使用 SHA-256 加盐哈希存储，仅用于本机账号切换的弱校验，不构成网络安全防护。
- 同组协作为「本机多账号 + 本地存储」的方案 A：通过加入码 / 邀请本机账号进入同一浏览器内的小组，不做跨设备同步。
- 代码题不在线运行，作答保存后由本人 / 组长人工批改。
