# 工作生活助手 · 桌面版（Electron）

把现有网页版应用封装成 Windows 桌面程序：双击图标即进入应用，不再依赖浏览器标签页和命令行。
业务前端代码（`app/`）零改动，桌面壳只负责提供运行时窗口与本地静态服务。

## 一、直接打开（普通使用）

进入 `dist-win\win-unpacked\`，双击 **`工作生活助手.exe`** 即可启动。

- 整个 `win-unpacked` 文件夹是一个整体；拷贝或移动时请整目录一起复制，不要只单独拷 exe。
- 首次启动会弹出独立窗口，标题为「工作生活助手」。

## 二、开发调试

```
cd desktop
npm install
npm start
```

## 三、重新打包

```
npm run dist
```

产物输出到 `dist-win\win-unpacked\`（绿色目录版：主程序 exe + Electron 运行时 + 业务前端资源）。

## 四、数据说明（重要）

- 桌面版使用**独立**的本地数据存储（独立用户数据目录 + 本地服务地址 `127.0.0.1:8788`），
  与之前浏览器里 `127.0.0.1:8000` 的数据**互不相通**。
- 从浏览器版迁移：先在浏览器版「设置 → 导出备份」得到 JSON 文件，
  再在桌面版「设置 → 从备份恢复」导入即可。
- 数据保存在本机用户数据目录，删除 `win-unpacked` 程序目录不会自动清除历史数据。

## 五、技术要点

- `main.js`：主进程。内嵌极简静态服务加载 `app/`，负责创建窗口、安全策略与生命周期；
  目录穿越已做拦截，外部链接交给系统浏览器打开。
- 安全配置：`contextIsolation: true`、`nodeIntegration: false`，渲染层不直接接触 Node。
- 打包：`electron-builder`，通过 `extraResources` 将 `app/` 原样放入 `resources/app`。
- 渲染层在 `http://127.0.0.1` 下运行，IndexedDB 正常可用，业务逻辑无需适配。

## 六、当前形态与后续可选项

- 当前为**绿色目录版**（exe 与运行时同目录，解压即用）。
- 单文件 portable 安装包依赖 NSIS 与代码签名工具链，其中包含 macOS 符号链接；
  在当前非管理员、未开启 Windows 开发者模式的环境下无法创建符号链接，故暂未产出单文件 exe。
  若后续需要单文件 exe：开启「设置 → 隐私和安全性 → 开发者选项 → 开发人员模式」，
  或以管理员身份运行打包命令，并将 `package.json` 中 `win.target` 改回 `portable` 即可。
